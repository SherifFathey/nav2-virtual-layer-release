Changelog for package nav2_virtual_layer
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

0.0.1 (2026-11-26)
------------------
* Initial release of nav2_virtual_layer for ROS 2 Jazzy.
* Dynamic virtual restriction layer for Nav2 costmap 2D.
* Support dynamic shapes: Circle, Line, Polygon.
* Add services for adding and removing shapes (AddCircle, AddLine, AddPolygon, RemoveShape).
* Support shape ID system, ID-based removal, and reload service.
* Support time-based shape expiration (duration).
* Add visualization markers support in RViz.
* Contributors: Sherif Fathey
